# ADR-003：频率统计排序公式设计

- 状态：已接受
- 日期：2026-09-15

## 决策
候选命令得分：

```
score = log(1 + count) × decay(age) × context
decay(age)   = 0.5^(age / 30d)      # 半衰期 30 天的时间衰减
context      = 1.5 当 (同目录 ∨ 同前缀 ∨ 链式关系)，否则 1.0
```

收藏（favorites）额外获得 rankScore 保底 2.0，保证"收藏 > 历史"。

链式关系：以最近历史中"同父命令且不在当前候选集"的最早一条为锚点，
与之最近的后随命令 ×1.5；无锚点时全部 ×1.0（避免污染）。

## 理由
- `log(1+count)` 抑制高频命令的边际优势（1000 次 ≠ 100 次的 10 倍）；
- 指数时间衰减让"上周高频"优于"三个月前高频"，贴合真实使用节奏；
- 上下文加成体现"越用越懂你"：同一目录下重复的命令优先。

## 后果
- 排序结果可复现（纯函数，内部 rank 包 96.2% 覆盖率）；
- 提供 `cmdpilot stats top/trend/distribution/clear` 查看与清除。
